# LifeOS + Fabric Learnings for CHIMERA

CHIMERA should use the same ecosystem capability and verification conventions.

- Represent coding work as desired state plus acceptance/evidence criteria.
- Express reusable coding behaviors as capability contracts rather than model-specific prompts.
- Allow DMR-X to adaptively select models or non-LLM workers.
- Record execution and verification receipts for important work.
- Distinguish agent claims from verified outcomes.
- Consume NOESIS context and ecosystem capabilities only through explicit contracts and permissions.

CHIMERA remains a coding agent; it does not become the personal self-model, memory OS or governance kernel.
